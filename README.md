# Be My Valentine 💕

A cute, static **Valentine's Day website** built with HTML, CSS, and JavaScript, and hosted for free on **GitHub Pages**. Personalize it with your crush's name and send them the link to ask the big question!

## Live demo

See it in action here: **https://ryan-adams57.github.io/BeMyValentine/**

## What's inside

- `index.html` - the main web page and its content.
- `style.css` - the styling that gives the page its Valentine's look.
- `main.js` - the interactivity that makes the page fun.
- `Instructions` - a step-by-step setup guide (also summarized below).

## Make it your own

The site is intentionally simple: you really only need to change one thing, the recipient's name.

1. **Get the code.** Clone or download this repository.
2. **Edit the name.** Open `index.html` in any code editor, find the header section, and replace the example name with whoever you're sending it to. Save the file when you're done.

> **Important:** Don't rename the file. It must stay `index.html` for GitHub Pages to work.

## Publish it with GitHub Pages

Once you've personalized the page, you can put it online for free:

1. On GitHub, click **New repository**, give it any name, set it to **Public**, and create it.
2. Upload your edited `index.html` (along with `style.css` and `main.js`) and commit the changes.
3. In your repository, go to **Settings -> Pages**.
4. Under the branch/source setting, select your main branch and save.
5. Give it a minute, then visit the GitHub Pages URL it generates. Your Valentine site is live!

Share that link with your special someone and fingers crossed for a yes. 💝

## Customize further

Want to go beyond the name? Open `style.css` to tweak colors, fonts, and layout, or edit `main.js` to change the interactive behavior. Make it as personal as you like.
